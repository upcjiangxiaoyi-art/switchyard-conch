# 🛤️ 枢轨 · Switchyard

SillyTavern 智能预设路由器。枢轨自动给主 AI 贴入一条极短路由协议；主 AI 在正文最后一行写模式标记，枢轨读到就把**整套酒馆预设**切到当前文体对应的那一套，场景结束自动切回原预设。

```
<route>nsfw</route>      → 野渡 切 野渡·NSFW，佩安 切 佩安·NSFW
<route>normal</route>    → 切回进入前的那套
```

## 它做什么、不做什么

- 读标记，切预设。只自动贴入一条极短路由协议，不改你的预设内容；也可以关闭自动贴入，改为手动复制。
- 自动从聊天显示层隐藏路由标记，但保留消息原文，重 roll 与历史校对仍有凭据。
- 每个聊天单独记：原预设、当前模式、切去了哪、该回哪、是否手动锁定。换聊天各回各的。
- 映射表显式行优先，`{base}·NSFW` 模板行兜底。没有对应预设就**不切并提示**，宁可不换不能换错。
- 切换发生在 AI 楼落地那一刻，下一轮生成前预设已经换好。重 roll 时按被 roll 那楼之前的一楼重新校对；切换已有 swipe、删楼或编辑楼层后也会重新对账。
- 你手动换预设，枢轨认账：新预设成为新的基础，模式回 normal，不会下一楼又给你切回去。
- 只用酒馆公开的预设管理器接口，精确匹配预设名，绝不模糊匹配。

## 安装

作为 SillyTavern 第三方扩展，用下面的仓库地址安装：

```
https://github.com/upcjiangxiaoyi-art/switchyard-conch
```

设置在扩展抽屉「🛤️ 枢轨 · Switchyard」。

## 用法

1. 给每套文体做一个 NSFW 版预设，按命名约定叫 `文体名·NSFW`（后缀可在映射表模板行里改）。
2. 打开枢轨开关。映射表默认有一行：模式 `nsfw`，任意预设 → `{base}·NSFW`。要特殊对待的文体再加显式行。
3. 保持「自动给主 AI 贴入极短路由协议」开启；你的预设本体不需要增加路由文字。若关闭，再把抽屉里的协议预览手动复制进每一套会参与路由的预设。
4. 路由标记默认由枢轨自动隐藏，不需要另写酒馆正则。
5. 模型判断错了，用「本聊天手动锁定」拨回来；改回「自动」继续听标记。

标签名可配多个，默认 `route, ipe_mode`，与小海螺的挂账场景模式共用一个标记，主 AI 只写一次。
